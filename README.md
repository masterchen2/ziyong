# IP地址批量检测工具

这是一个使用Python开发的IP地址批量检测工具，可以同时检测多个IP地址是否在线，并显示延迟时间。

## 功能特点

- 批量输入IP地址进行检测
- 多线程并行检测，提高效率
- 直观的图形用户界面
- 实时显示检测进度
- 结果以不同颜色区分在线和离线状态
- 支持打包成独立的可执行文件

## 使用方法

### 直接运行Python脚本

1. 确保已安装Python 3.6或更高版本
2. 运行`ip_checker.py`文件：
   ```
   python ip_checker.py
   ```
3. 在文本框中输入要检测的IP地址，每行一个
4. 点击"开始检测"按钮

### EXE文件直接运行

1.下载EXE文件，
4. 双击`IP地址批量检测工具.exe`即可运行程序

## 程序界面说明

- 上方文本框：输入要检测的IP地址，每行一个
- 开始检测：开始检测所有输入的IP地址
- 清空结果：清空下方的检测结果
- 进度条：显示当前检测进度
- 下方文本框：显示检测结果，绿色表示在线，红色表示离线

## 注意事项

- 检测结果会显示IP地址、状态（在线/离线）和延迟时间
- 程序会自动对IP地址进行排序
- 检测完成后会显示统计信息（总计、在线、离线数量）
- 打包过程可能需要几分钟时间，请耐心等待
